# 原神乐器 MIDI 播放器

Windows 桌面程序：读取 MIDI 音符、选择截图所示的乐器键位布局，并通过 Windows SendInput 按键演奏。

## 启动

在项目目录运行：

    .\.venv\Scripts\python.exe main.py

也可以先激活 .venv，再运行 python main.py。
程序会检查管理员权限；若当前未提权，将请求 Windows UAC 确认并以管理员权限重新启动。取消提示或启动失败时，程序会退出。

## 使用

1. 选择 MIDI 文件，在声部列表中勾选需要合并演奏的音轨；默认勾选所有含音符的音轨。每个声部可独立选择关闭、单音近似或和弦近似。
2. 选择乐器布局，点击“自动转调”寻找更适配该音阶与音域的偏移，也可手动调整。单音近似会将音域内缺失半音映射到最近可演奏音；和弦近似优先映射到最近可用和弦，孤立的缺失半音也会近似为和弦。预览会显示替代结果；音域外音符仍会跳过并显示警告。
3. 在游戏内打开对应乐器后，按 F7 开始或继续，F8 暂停，F9 重置。也可以用窗口中的按钮。

暂停、重置、结束和输入异常都会尝试释放仍按住的键。全局热键若与其他程序冲突，窗口状态栏会提示，仍可使用窗口按钮。

## 当前映射

- 标准音部：三排自然七声音阶，键位 Z-M、A-J、Q-U。
- 类吉他：C、Dm、Em、F、G、Am、G7 和弦键，以及两排单音键。
- 特殊调式：do、降 re、降 mi、fa、sol、降 la、降 ti；按 do=C 表示 C Phrygian。
- 女声 / 中低音部：两排自然七声音阶。

截图没有标出绝对 MIDI 八度。目前标准音部和特殊调式从 MIDI 48 开始，类吉他和女声/中低音部从 MIDI 60 开始。这些是可通过自动或手动转调调整的初始假设，尚未在游戏内校准。严格模式下不支持的音高会跳过；近似模式只近似乐器音域内的缺失音高，音域外音符仍显示警告并跳过。标准音部、特殊调式和女声/中低音部会把同时出现的和弦音映射为多个同时按下的单音键；类吉他则优先使用其固定和弦键，近似模式会将无法识别的和弦匹配到最接近的可用和弦并提示结果。速度力度（velocity）忽略；tempo、音长、休止和重叠音符按 MIDI 事件时间处理。

## 验证

    .\.venv\Scripts\python.exe -m pytest -q

自动化会向当前焦点窗口发送键盘输入。是否符合游戏规则由使用者确认。程序仅使用普通 Windows 输入和全局热键 API，不读取游戏进程、不注入代码，也不尝试绕过反作弊。
